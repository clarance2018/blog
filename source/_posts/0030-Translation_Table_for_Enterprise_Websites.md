我之前帮一个朋友的公司改网站，发现英文版的"关于我们"写着："We are a professional company focusing on……"

听得出来是机翻的。但这不是最离谱的。

最离谱的是**英文菜单里有一项叫"Product Display"**——中文版对应的菜单是"产品展示"。这翻译没什么问题，问题是：**英文版的其他菜单全翻错了，这一项误打误撞对了。**

后来我问他们：你们英文版有外国人访问吗？他们说：有，比例还不少。

从那天起我养成了一个习惯：看一个企业网站的英文版，就能大概猜出这家公司有没有真的在做海外业务。

**一句话理解：** 企业网站的英文翻译不是为了"看起来高级"，是为了**让说英语的用户真的能用**。

## 企业网站导航常用翻译

以下是按场景分类的企业网站翻译表，附加上下文说明，避免直译闹笑话。

### 顶部导航

| 中文 | English | 说明 |
|------|---------|------|
| 首页 | Home | 不要用 Homepage |
| 关于我们 | About Us | About 也接受，但 About Us 更自然 |
| 产品展示 | Products | 不是 Product Display |
| 新闻动态 | News | 或 News & Updates |
| 联系我们 | Contact Us | 确认用 Contact，不是 Contact Us……其实可以更短 |
| 加入我们 | Careers | 或 Join Us，但 Careers 更专业 |
| 常见问题 | FAQ | 全大写，不用写 Frequently Asked Questions |
| 下载中心 | Downloads | 不用 Download Center |

### 产品相关

| 中文 | English | 说明 |
|------|---------|------|
| 产品名称 | Product Name | 固定搭配 |
| 产品描述 | Description | 不用 Product Description，单 Description 即可 |
| 规格参数 | Specifications | 复数 |
| 型号 | Model | 不加 No. |
| 产地 | Origin | 或 Country of Origin |
| 品牌 | Brand | 不用 Brand Name |
| 价格 | Price | 单数，List Price 或 Retail Price 可作区分 |
| 在线订购 | Order Online | 不要用 On-line Order |

### 公司信息

| 中文 | English | 说明 |
|------|---------|------|
| 公司简介 | About | 在国外网站上很少看到"Company Profile" |
| 企业文化 | Culture | 很 OK |
| 发展历程 | Our History | 不用 Development History |
| 荣誉资质 | Certifications | 比 Honors 更贴切 |
| 合作伙伴 | Partners | 用 Partners 一个词就行 |

### 联系我们

| 中文 | English | 说明 |
|------|---------|------|
| 地址 | Address | 简写 Add 不合适 |
| 电话 | Phone | Tel 太正式，Phone 更好 |
| 邮箱 | Email | 不用 E-mail |
| 邮编 | ZIP Code | 美国用 ZIP Code，其他国家用 Postal Code |
| 提交 | Submit | 表单按钮通用 |
| 重置 | Reset | 小心使用，用户点错了会生气 |

## 新增：SaaS 和云服务术语

2026 年了，很多企业网站已经不只是做"企业展示"，而是做 SaaS 服务了。这里补充一份：

| 中文 | English | 说明 |
|------|---------|------|
| 开始使用 | Get Started | 不要用 Start Use |
| 免费试用 | Free Trial | SaaS 标配 CTA |
| 登录 | Sign In | Log In 也可以，但不要用 Login（那是名词） |
| 注册 | Sign Up | 或 Register |
| 定价 | Pricing | 不要用 Price List |
| 功能特性 | Features | 一个词就行 |
| 集成 | Integrations | 复数是惯例 |
| 服务条款 | Terms of Service | 或 Terms & Conditions |
| 隐私政策 | Privacy Policy | 标准用法 |
| 帮助中心 | Help Center | 比 Documentation 更用户友好 |
| 仪表盘 | Dashboard | SaaS 标配 |
| API 文档 | API Docs | 或 API Reference |
| 工单 | Ticket | 或者是 Support Ticket |

> **经验之谈：** 我之前参与过的一个 SaaS 产品，第一次上线时英文版把"免费试用"翻译成了"Free Trial Use"——少了三个字母的区别，海外用户会说但觉得别扭。改回 Free Trial 后转化率小幅提升——不要低估措辞的力量。

## 容易踩坑的翻译

以下是我在实际项目中遇到过的"看起来对但实际不对"的翻译：

| 中文 | 错误翻译 | 正确翻译 | 为什么 |
|------|---------|---------|--------|
| 视频 | Video Frequency | Video | 认成"视频频率"了 |
| 注册 | Login | Sign Up / Register | Login 是"登录" |
| 购物车 | Shopping Cart | Cart | Shopping 多余 |
| 信息发布 | Information Release | Publish | Release 是"发布软件" |
| 用户协议 | User Agreement | Terms of Use | 行业惯例用 Terms |
| 联系客服 | Contact Service | Contact Support | Service 和 Support 不同 |
| 关于 | About | About Us | About 偏介词，About Us 是标准 | 

## 企业网站英文版的终极建议

我给朋友的网站改版时，做了一个很简单的改动：**把他们的英文菜单从 8 项精简到 4 项。**

Home → Products → About Us → Contact

海外用户看到 8 个菜单项的反应其实和中国用户看到 8 个菜单项一样——**会选择忽略**。导航越少，每一个菜单项的价值越高。

还有一个建议：**如果你的英文版本没有专人维护，不如不要**。比没有英文版更尴尬的是——英文版的内容半年不更新、翻译错误百出、链接指向中文页。这些会给潜在海外客户留下"你们不专业"的印象。
