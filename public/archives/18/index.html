网站基础术语入门——你该知道的 20 个核心概念

发表于2020-06-11|更新于2026-07-24|Web开发
|浏览量:

我刚开始学做网站的时候，最痛苦的不是写代码——是看不懂别人在说什么。

“你把 CSS 写到 style 里，路径用相对路径，图片用 CDN，别忘了加 SSL……”

我当时内心：CSS 是什么？路径还分相对和绝对？CDN？SSL？ 每一个词都认识，连在一起就是天书。

如果你也有这种感觉，不要慌——这些术语第一次接触谁都懵。 我花了整整两年才把”这堆名词到底对应什么”搞明白。这篇帮你一次性理清。

一句话理解： 网站技术术语就像工具箱里的工具——你不需要认识所有工具才能用，但了解核心的几个，就能和任何开发者顺畅交流。

前端三件套（你每天看到的）

术语 一句话解释 类比
HTML 网页的结构骨架 房子的框架和墙壁
CSS 网页的样式皮肤 房子的装修和配色
JavaScript（JS） 网页的交互行为 房子的开关、门铃等智能功能

网络相关（连接后端和用户）

术语 一句话解释 类比
HTTP/HTTPS 浏览器和服务器之间”说话”的协议 快递的运输规则
SSL/TLS 给 HTTP 加一层加密保护 快递的加密包裹
DNS 把域名翻译成 IP 地址的服务 电话簿，把名字转成电话号码
CDN 把文件缓存在离用户最近的服务器 在全国各地建分仓库

关于 SSL/TLS 的详细说明，我专门写了完整的科普文章，但这里先说一句：2026 年所有网站必须上 HTTPS，没有例外。 这不是什么加分项，是基本要求。

路径与地址

术语 定义 示例
域名 网站的”门牌号”，方便人类记忆 6mal.com
IP 地址 服务器的真实坐标 124.220.71.26
绝对路径 从根目录开始的完整地址 https://6mal.com/archives/18/
相对路径 相对于当前文件的位置 ../images/logo.png
根目录 网站的”老家”文件夹 /var/www/html

绝对路径和相对路径的区别是很多新手的第一个坑——我专门写了一篇详细的解释。简单说就是：绝对路径告诉你怎么去”北京天安门”，相对路径告诉你”从前门地铁站往北走 200 米”。

经验之谈： 我刚做网站时犯过最蠢的错误：把所有图片链接写成了绝对路径 http://localhost/images/abc.jpg。上传到服务器后所有图片全挂——因为服务器上没有”localhost”。从那以后我写路径一律用相对路径。

后端与数据库（看不见的部分）

术语 一句话解释 常见例子
Web 服务器 接收请求并返回网页的程序 Nginx、Apache、Caddy
后端语言 在服务器上运行的代码 PHP、Node.js、Python、Java
数据库 存储网站数据的系统 MySQL、PostgreSQL、Redis
API 程序之间”对话”的接口 REST API、GraphQL

2026 年的一个重要变化： “后端”这个概念正在被 Edge Functions 和 Serverless 模糊化。你现在可以写一个 JavaScript 函数，既不放在”前端”也不放在”后端”，而是部署在 CDN 节点上——这就是 Edge Computing。

工具与环境

术语 一句话解释 类比
框架 别人写好的代码脚手架 盖房子的预制件
CMS 不用写代码就能管理内容的系统 WordPress、Hexo 这类
Git 代码的”版本控制”工具 游戏的存档功能
包管理器 自动下载和管理第三方代码库 手机的应用商店
CLI 用命令行操作的工具 输入指令来控制电脑

我建议新手的掌握顺序

如果你刚开始学做网站，不要试图一次性搞懂所有术语。按这个顺序来：

  1. HTML + CSS（能做一个显示出来的页面）
  2. 域名 + 服务器 + 部署（让页面被大家访问到）
  3. HTTP/HTTPS + SSL（让你的网站安全）
  4. JavaScript + 框架（让你的网站交互）
  5. 后端 + 数据库 + API（做真正的动态网站）

走到第 3 步，你已经可以做一个合格的”个人网站”了。 我自己的博客就是在第 3 步建立的（Hexo + Nginx + Let’s Encrypt），之后才慢慢扩展到后端和 API。

P.S. 这篇文章写给我的”十年前的自己”——那时候我对着屏幕上显示的 “404 Not Found” 一头雾水，不知道是路径错了还是服务器挂了。后来我学会了看错误日志，学会了区分”404”和”500”意味着不同的问题。学做网站，本质上就是学会理解这些”错误信息”的过程。别忘了，每一个让你抓狂的报错，都是你成长的路标。
