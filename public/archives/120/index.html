Meta 押注的东西，Codex 和 Claude Code 两周内也全上了：Agent 记忆之战开打

发表于2026-10-19|更新于2026-10-19|AI探索
|浏览量:

如果你在九月底问一个 AI 从业者“大模型下一步卷什么”，答案大概率是推理能力、多模态或者更便宜的 token。但十月中旬的两周里，几乎所有头部玩家不约而同地给出了同一个答案：记忆。

Meta 用一款模型宣告了方向。 10 月 13 日，Meta 超级智能实验室发布首款前沿级模型 Muse Wonder，成绩与 GPT-6 Astra、Fable 5.1 同处第一梯队——但真正让产品圈讨论的，是它把“主动记忆”和“主动专注”作为核心卖点：模型不只回答你问的，还会记住你此前会话里的偏好、项目和约束，并在合适的时机主动调用。扎克伯格的原话是“开发会明显提速”，而差异化抓手不是分数，是记性。

Coding Agent 阵营几乎同步行动。 过去两周，Codex、Claude Code、Goose、OpenHands 集体把会话历史从“滚动日志”升级为“一等检索目标”：Codex 的 Guardian 功能允许 Agent 在十几轮之后，把你在第一轮说过的架构决策和“别碰这个文件”重新捞回来；Claude Code 则从另一个方向解决问题——单次读取超大文件、让子代理提前压缩上下文，本质都是在做上下文经济学。有人把这一波称为 Memory Wars 的开场。

第三个信号来自国内。 豆包工作本周上线一键迁移功能，可以把 ChatGPT、Claude Code、Trae 的对话历史、技能与记忆整体搬过来，且保留原始上下文。这件事的意味很微妙：记忆第一次被当成可迁移的资产。平台不再只是抢用户，而是在抢用户的“Agent 人格”。当你的 AI 助手积累了三个月的项目记忆，迁移成本就成了新的锁定——反过来，谁先支持迁移，谁就在争夺“不锁定”的口碑。

为什么是现在？答案藏在上一阶段的教训里。过去一年 Agent 落地的最大瓶颈不是不够聪明，而是不稳定：第 16 轮之后忘记第 2 轮的约定、重复踩已经解释过的坑、长会话幻觉出根本不存在的文件。用户手动维护 AGENTS.md、手动 /compact，本质都是在替 Agent 记忆。当模型能力进入平台期，谁把“记性”做成产品，谁就接住了 Agent 从玩具变成同事的关键一环。

当然，硬币的另一面已经在安全圈敲响警钟。记忆意味着状态持久化，而持久化状态意味着新的攻击面——记忆投毒（往 Agent 的长期记忆里塞恶意指令）已经被列入 2026 年 Agent 安全的核心议题。行业还没想清楚：你的 AI 记住的关于你的一切，存在哪、归谁、泄露了算谁的。

给从业者的三个实用要点：

  • 把 prompt 排序当架构决策：稳定内容前置、增长内容后置，缓存命中率是要盯的指标，不是背景噪音——OpenAI 的缓存输入折扣最高已达 90%。
  • 选工具时问一句“它怎么记住你”：会话检索（Guardian 式）、外部记忆文件（AGENTS.md 式）、主动记忆（Muse 式）是三条不同的产品路线，决定你的长期数据落在哪。
  • 警惕记忆黑箱：在把项目记忆交给任何平台之前，确认导出路径和删除路径。豆包们已经证明记忆可以迁移，不支持迁移的记忆，才是真正该担心的。

记忆之战才刚刚开场。模型分数的差距在缩小，记性的差距在拉开——下次选 AI 工具，别只问它多聪明，先问它记不记得住你。
